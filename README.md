## Обо мне

Системный архитектор. Сейчас строю платформу автоматизации бизнес-процессов в банке из ТОП-5.
На предыдущем проекте — **300+ микросервисов** в high-load окружении.

Проектирую системы, которые выдерживают нагрузку, остаются наблюдаемыми и не рассыпаются при росте.
Интересуюсь распределёнными системами, потоковой обработкой (Kafka / Kafka Streams), проектированием
данных (PostgreSQL, шардирование, ClickHouse, Redis) и интеграцией LLM в продуктовые системы.
